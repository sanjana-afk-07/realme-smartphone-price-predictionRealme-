
# Realme Smartphone Price Prediction

## Project Overview
This project uses Machine Learning to predict
the price of Realme smartphones based on their
specifications.

## Algorithm
Random Forest Regressor

## Input Features
- RAM
- Storage
- Battery capacity
- Camera
- 5G support

## Output
Predicted smartphone price in Indian Rupees.

## Technologies
- Python
- Pandas
- Scikit-learn

## How to Run
Install the required libraries:

pip install pandas scikit-learn

Run the Python file:

python realme_price_prediction.py

## Note
The current dataset is sample data for learning.
